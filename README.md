# All of Statistics — Solutions
 
A repository of my original solutions to problems from *All of Statistics: A Concise Course in Statistical Inference* by Larry Wasserman.
 
## Contents
 
- **Non-computational problems** (proofs, derivations, and calculations done by hand) are written in **Markdown**, with math typeset in LaTeX.
- **Computational problems** (simulations, data analysis, and plots) are provided as **Jupyter notebooks** (`.ipynb`), so the code can be run and the results reproduced.
## How these solutions were made
 
All problems were solved by me, without the use of AI. Each solution was first handwritten on a tablet.
 
AI was used only for two supporting tasks:
 
1. **Transcription**: converting my handwritten solutions into Markdown and LaTeX.
2. **Verification**: checking the finished solutions for errors.
The reasoning, methods, and answers are my own.

## Disclaimer
 
These are personal solutions and may contain mistakes. If you spot an error, feel free to open an issue.
 
## Reference
 
Wasserman, L. (2004). *All of Statistics: A Concise Course in Statistical Inference*. Springer.
